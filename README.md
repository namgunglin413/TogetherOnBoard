# Together On Board

보드게임을 장르별로 찾아보고, 인원수에 맞춰 무작위로 추천받을 수 있는 보드게임 커뮤니티 웹사이트
대학교 웹프로그래밍 수업의 3인 팀 프로젝트로 제작

- 배포 사이트: https://creative-marigold-bd51b0.netlify.app/
- 기간: 5주 (주제 선정부터 배포까지)
- 팀 구성: 3명 (김예인, 김혜나, 남궁린)

## 주요 기능

| 메뉴 | 기능 |
| --- | --- |
| 메인 | 이미지 슬라이드, 메뉴바, 전체 페이지 이동 |
| 게임 리스트 | 보드게임 목록, 검색, 장르별 필터링, 상세 페이지 |
| 랜덤 룰렛 | 2인·4인·6인 인원별 보드게임 무작위 추천 |
| 리뷰 | 별점과 리뷰 게시판 |
| 공지사항·이벤트 | 공지 목록과 상세 페이지, 시즌별 이벤트 페이지 |
| FAQ·커뮤니티 | 자주 묻는 질문, 커뮤니티 게시판 |

## 기술 스택

- HTML, CSS, JavaScript, jQuery
- Netlify (정적 사이트 배포)

## 담당 역할 (남궁린)

- 메뉴바, 공지사항·이벤트·FAQ·커뮤니티 페이지, 리뷰 게시판 틀 구현
- 보드게임 상세 페이지 디자인(색상, 텍스트 형식)과 페이지에 들어갈 이미지 제작
- 팀원 3명의 코드를 하나로 합치면서 메뉴바와 다른 코드의 충돌을 확인하고 수정
- 전체 디자인 통일, 웹서버 등록(배포), 스토리보드 작성과 발표 자료 제작

## 협업 방식

- 5주 동안 회의 15회를 진행하고 회의록으로 진행 상황을 기록
- 주마다 각자 결과물을 공유하고 중간 점검과 피드백 진행
- 마지막 주에 코드 통합, 디자인 일관화(글씨체, 간격, 색상), 오류 검토 진행

## 폴더 구조

```
├── index.html          # 시작 페이지 (메뉴바 + 메인 슬라이드)
├── MainSlide.html      # 메인 화면
├── 게임/               # 게임 리스트, 랜덤 룰렛
├── 리뷰/               # 리뷰 게시판
├── 공지사항/           # 공지 목록·상세, 이벤트 창
├── 이벤트/             # 이벤트 페이지
├── FAQ/                # 자주 묻는 질문
├── 커뮤니티/           # 커뮤니티 게시판
├── 메인화면/           # 메인 이미지·스타일·스크립트
├── css/, favicon/      # 공통 스타일, 파비콘
```

## 실행 방법

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나 배포 사이트에서 확인할 수 있습니다.
